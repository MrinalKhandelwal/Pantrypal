# 🍳 PantryPal

PantryPal is a React-based recipe finder application that helps users discover recipes based on the ingredients they already have.

Instead of searching for a recipe first, users can enter the ingredients available in their kitchen, and PantryPal finds relevant recipes and shows how well those ingredients match each recipe.
